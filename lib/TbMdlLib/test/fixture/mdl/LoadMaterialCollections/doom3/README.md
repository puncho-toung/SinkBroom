# Doom 3 material pipeline fixtures

Synthetic fixtures for `tst_LoadMaterialCollections.cpp` and `tst_LoadShaders.cpp`, with no id Software data: the `.mtr` files were written by hand with made-up names, and every image was generated by a script as a single-colour PNG or TGA whose size identifies it in the tests (one PNG has binary alpha). The two `.dds` files are copies of `LoadDdsTexture/dds_bc1_npot.dds`, a 20x12 DXT1 texture with the full mip chain 20x12, 10x6, 5x3, 2x1, 1x1 in which every block of a level has that level's RGB565 colour: 0xF800, 0x07E0, 0x001F, 0xFFE0 and 0x8410.
